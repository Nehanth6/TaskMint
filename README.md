# TaskMint — Student Academic Services Platform

A modern, responsive web application for **TaskMint** built with React, Vite, and Tailwind CSS, faithfully matching the **Student Startup (Vibrant & Youthful)** visual reference.

---

## 🎨 Visual Identity & Key Features

- **Reference Image Match**:
  - Crisp **TaskMint** origami leaf/plane branding and typography.
  - Soft pastel background blobs (`#FCFBFF`, `#FFE98A`, `#B7F3D0`, `#ECE6FF`, `#FCE7F3`).
  - Top navigation with smooth section scrolling (`Home`, `Services`, `How It Works`, `Reviews`, `FAQ`) plus `Login` and purple `Get Started` actions.
  - Badge: `"Your College Task Partner"`.
  - Headline: **"Same Deadlines. Less Stress."** with `#6546F5` purple emphasis.
  - Authentic visual asset of the **three smiling college students** giving thumbs-up with playful doodles and the `"Submit. Relax. Excel!"` motto.
  - **Four white horizontal service cards** across the bottom of the hero section with pastel icon boxes and circular arrow buttons:
    1. **PPT Design** (`/services/ppt-design`)
    2. **Project Reports** (`/services/project-reports`)
    3. **Handwritten Assignments** (`/services/handwritten-assignments`)
    4. **Lab Records** (`/services/lab-records`)

- **Additional Homepage Sections**:
  - **Interactive Instant Estimate Tool**: Students can adjust quantity and urgency to calculate instant transparent pricing.
  - **How It Works**: 4-step progressive flow (Select service, provide requirements, view price, place order).
  - **Why TaskMint**: Clear pricing, convenient ordering, live progress updates, and dual-stage quality review.
  - **Reviews & Quality Benchmarks**: Authentic platform standards, rubric match, free revision policy, and genuine student feedback policy (no fabricated testimonials).
  - **FAQ Section**: Accordion answering quotations, deadlines, delivery formats, and confidentiality questions.
  - **Footer**: Brand links, services directory, student helpdesk contact info, and academic integrity statement.
  - **Dedicated Service Routes**: Each service card routes to a detailed specification page with a task order request form.
  - **Student Auth Modal**: Simulated login and registration workflows accessible from the top navbar.
